아이폰에서 갤럭시로 갈아타려는데, 갤럭시에서 에어팟 그대로 계속 써도 될까?

아이폰에서 갤럭시로 넘어오면서 가장 먼저 걸린 게 에어팟이었어요. 에어팟 잘 되는데, 굳이 버즈로 바꿔야 하나 한참 고민하다가, 일단 에어팟 프로2를 그대로 연결해서 써봤습니다.

판단 기준부터 밝히고 시작할게요!

이 글의 판단 기준이 저마다 다를 수 있어서, 제 사용 환경을 먼저 말씀드릴게요.

  • 에어팟 프로2를 메인으로 사용
  • 추후 버즈3 구매
  • 음질보다는 노캔, 통화, 출퇴근길 편의성이 더 중요한 편

이 기준으로 갤럭시에서 에어팟을 며칠 써본 결과를 정리했어요.

에어팟 vs 버즈, 체감 차이는 이 정도였어요

직접 써본 기준으로 간단히 비교하면 이래요.

  • 노이즈 캔슬링 : 체감상 에어팟이 우세해요. 에어팟 쓰다가 버즈로 넘어오면 살짝 역체감이 올 수 있어요
  • 음질 : 막귀 기준으로는 둘 다 비슷했어요
  • 통화 품질 : 버즈 쪽이 좀 더 나았어요
  • 편의성 : 갤럭시에선 버즈, 아이폰에선 에어팟이 편한 건 당연한 얘기죠

이 정도 차이 때문에 굳이 멀쩡한 에어팟을 버즈로 바꿀 정도는 아니라고 판단했어요.

결론부터, 갤럭시에 에어팟 그냥 연결해서 써도 생각보다 멀쩡했어요

블루투스로 연결만 해도 아래 기능은 문제없이 됐어요.

  • 음악 재생
  • 영상 시청
  • 통화, 전화 받기/끊기
  • 노이즈 캔슬링
  • 주변음 듣기
  • 기본 제스처 (재생, 일시정지, 다음 곡 넘기기)

여기까지는 아이폰에서 쓰던 것과 체감 차이가 크지 않았어요.

그런데 쓰다 보니 아이폰에서 당연했던 기능이 빠져 있었어요

기본 기능은 멀쩡한데, 며칠 더 써보니 아이폰에서는 신경 쓸 필요도 없었던 부분이 하나씩 눈에 띄었어요. 사실 이 글에서 제일 중요한 부분은 여기예요.

  • 배터리 잔량을 정확한 퍼센트로 바로 확인하기 어려움
  • 착용 감지 연동 안 됨 (귀에서 빼면 멈추고 다시 끼면 재생되는 기능)
  • 기기 간 자동 전환 안 됨
  • Find My 연동 안 됨
  • 대화 인지 기능 빠짐 (말 시작하면 음악 소리 자동으로 줄여주는 기능)
  • 적응형 오디오 세부 설정 안 됨
  • 통화 제스처 세부 설정 (한 번/두 번 누르기로 받기, 끊기, 음소거 지정) 안 됨

이 목록만 보면 에어팟을 계속 쓰기엔 아쉬운 점이 많아 보이는데… 그쵸?

그래서 LibrePods이란 앱을 찾아봤어요.

기기와 One UI 버전에 따라 되는 범위가 달라서, 표로 먼저 정리할게요.

단순 블루투스 연결로 부족했던 부분을, 이 앱으로 얼마나 메꿀 수 있는지가 궁금해서 알아봤어요.

LibrePods 앱으로 실제 보완 가능한 기능

공식 문서 기준 지원 기능

  • 좌우 이어버드, 케이스 배터리 확인
  • 착용 감지
  • 노캔, 주변음, 적응형 모드 전환
  • 대화 인지
  • 자동 연결
  • 길게 누르기 제스처 설정
  • 통화 제스처 세부 설정

제가 직접 써본 범위

  • 기본 블루투스 연결
  • 노캔
  • 통화
  • 기본 제스처

이 네 가지는 제가 직접 확인한 부분이고, 배터리 확인이나 착용 감지 같은 LibrePods 고유 기능은 공식 문서 기준으로 정리한 내용이에요.

라이트 유저라면 배터리 확인, 노캔 모드 변경, 착용 감지 정도만 써도 꽤 만족스러울 거예요.
폴드8은 주요 기능을 무루팅으로 사용할 수 있어서, 하드유저가 아닌 이상 굳이 루팅까지 갈 필요는 없어 보여요.

설치 방법

LibrePods는 구글 플레이스토어 앱이 아니라 GitHub에서 APK를 직접 설치하는 방식이라, 설치 전 최신 릴리즈와 권한 안내를 확인하는 걸 권장해요.

LibrePods 공식 GitHub Releases

  1. release.apk 파일 다운로드(Asset의 저 release.apk를 다운받아주세요)
  2. APK 실행 후 설치

  3. 갤럭시에서 출처를 알 수 없는 앱 설치 허용
  4. 필요한 권한 허용
  5. 에어팟 연결 후 LibrePods에서 인식 확인

일단 그대로 써보시고, 정말 불편한 부분이 확인되면 그때 버즈를 고민해도 늦지 않을 것 같아요. 저도 꽤 오랬동안 에어팟2프로로 갤럭시에서 연명하다가, 버즈로 갈아탔으니까요.
