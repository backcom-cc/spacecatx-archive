## 아이폰 Face ID 안됨.. 예상가는 원인이 너무 많아요

요즘 눈썹 문신을 하고 입술에 필러도 살짝 했어요… 그런데 그날 이후로 아이폰 Face ID가 자꾸 말썽이더라구요. 처음엔 그냥 한두 번 그런가 보다 했는데, 종종이 아니라 꽤 자주 인식을 거부하기 시작했어요.

곰곰이 생각해보니 원인 후보가 한둘이 아니었어요. 눈썹 문신하고 입술 필러 때문에 얼굴이 달라져서 그런가 싶다가도, 그러고 보니 얼마 전에 iOS 업데이트도 했었거든요. 그것 때문일 수도 있겠다 싶었고요. 아니면 제가 폰을 워낙 잘 떨어뜨리는 편이라, 그러다 카메라 쪽이 미세하게 맛이 갔을 가능성도 있겠더라구요.

이것저것 재설정도 해보고 재부팅도 해봤는데 그때그때 다르게 되다 안 되다를 반복하니까, 도대체 뭐가 진짜 원인인지 감을 잡기가 힘들었어요.

그래서 이번 글에서는 Face ID가 안 되는 상황을 계기별로 나눠서 정리해보려고 해요. 업데이트 이후부터 그런 건지, 외모가 변한 뒤부터 그런 건지, 떨어뜨리거나 물에 닿은 적이 있는지, 아니면 그냥 이유 없이 종종 그런 건지, 혹은 아예 설정 자체가 막혀서 활성화가 안 되는 건지에 따라 원인도 해결 방향도 완전히 달라요.

지금 어떤 상황에 제일 가까운지부터 한번 짚어볼게요.

## 아이폰 Face ID 안됨 내 Face ID는 어떤 상태일까?

Face ID가 안 되는 이유는 정말 다양해요. iOS 업데이트 때문일 수도 있고, 외모 변화 때문일 수도 있고, 설정이 꼬였거나 TrueDepth 센서 자체가 고장 난 경우도 있고요.

먼저 아래에서 지금 내 상황과 제일 비슷한 항목부터 찾아보세요.

| 내 상황 | 먼저 볼 해결 방향 | 자가 해결 가능성 |
| --- | --- | --- |
| **iOS 업데이트 후부터 느려지거나 자주 실패** | 강제 재시동 > Face ID 재설정 > 모든 설정 재설정 | **★★★★☆ 높음** |
| **성형, 필러, 수염, 체중 변화 후 나를 못 알아봄** | 암호 입력으로 재학습 > 대체 외모 추가 > 필요하면 재등록 | **★★★★★ 매우 높음** |
| **떨어뜨림, 침수, 배터리 팽창, 수리 후부터 안 됨** | 전원 끄기, 건조 > 수리 이력 확인 > TrueDepth 점검 | **★☆☆☆☆ 낮음** |
| **별다른 계기 없이 됐다 안 됐다 하거나 재등록도 어려움** | 센서 청소, 필름 제거 > 재시동, 재등록 > 증상 영상 남기기 | **★★☆☆☆ 낮음** |
| **토글이 회색이거나 비활성화, TrueDepth 오류가 뜸** | 회색 토글은 주시 설정 확인 > 비활성화, 오류 문구는 하드웨어 점검 | **★★★☆☆ 증상에 따라 다름** |

자가 해결 가능성이 낮게 나왔다고 해서 바로 고장으로 단정할 필요는 없어요. 특히 토글이 회색으로 표시되거나 Face ID 비활성화, TrueDepth 오류 문구가 나타나는 경우는 원인이 완전히 다를 수 있으니, 아래에서 해당 증상을 따로 확인해보세요.

## 1. iOS 업데이트 후부터 이상하다면 강제 재시동부터 순서대로 해보세요

iOS를 업데이트한 직후부터 Face ID 인식이 느려지거나, 전에는 한 번에 열리던 잠금 화면이 자꾸 암호 입력으로 넘어가는 경우가 있어요.

업데이트 시점이랑 증상이 겹쳤다면 바로 센서 고장부터 의심하기보다, 먼저 소프트웨어 쪽 문제일 가능성을 짚어보는 게 순서예요.

### 1) 아이폰을 강제 재시동해보세요

전원을 껐다 켜는 것보다는 강제 재시동을 먼저 시도해보는 걸 추천해요.

1. 음량 높이기 버튼을 빠르게 눌렀다 떼기
2. 음량 낮추기 버튼을 빠르게 눌렀다 떼기
3. Apple 로고가 나타날 때까지 측면 버튼 길게 누르기

중간에 전원 끄기 화면이 뜨더라도 버튼에서 손을 떼지 말고, Apple 로고가 나올 때까지 계속 눌러주세요.

### 2) Face ID를 재설정하고 다시 등록해보세요

강제 재시동 후에도 인식이 계속 불안정하다면, 저장된 얼굴 정보를 지우고 다시 등록해보세요.

```
설정 > Face ID 및 암호 > 암호 입력 > Face ID 재설정
```

재설정한 뒤 **Face ID 설정**을 눌러 현재 얼굴을 다시 등록하면 돼요. 이 과정에서 사진이나 앱 같은 데이터는 전혀 삭제되지 않으니 걱정 안 하셔도 돼요.

### 3) 그래도 안 되면 모든 설정을 재설정해보세요

Face ID를 다시 등록한 뒤에도 업데이트 이전처럼 돌아오지 않는다면, 마지막으로 모든 설정 재설정을 시도해볼 수 있어요.

```
설정 > 일반 > 전송 또는 iPhone 재설정 > 재설정 > 모든 설정 재설정
```

사진, 앱, 메시지 같은 개인 데이터는 지워지지 않지만, Wi-Fi나 개인정보 보호, 위치, 키보드 같은 일부 시스템 설정은 기본값으로 돌아갈 수 있어요. 그래서 처음부터 이 방법을 쓰기보다는, 강제 재시동과 Face ID 재설정으로도 해결이 안 될 때 마지막 순서로 시도하는 게 좋아요.

다만 얼굴을 다시 등록하는 과정에서 아이폰이 얼굴을 아예 감지하지 못하거나 **Face ID를 사용할 수 없음**, **TrueDepth 카메라에 문제가 감지되었습니다** 같은 문구가 뜬다면, 단순 업데이트 문제가 아닐 수도 있어요. 이럴 땐 뒤에서 설명할 TrueDepth 센서 이상 항목도 같이 확인해보세요.

강제 재시동과 Face ID 재설정 후에도 문제가 계속된다면, [애플 공식 Face ID 문제 해결 안내](https://support.apple.com/ko-kr/118243)에서 추가 점검 항목을 확인해보세요.

## 2. 외모가 달라진 뒤 Face ID가 안 된다면 현재 얼굴을 다시 학습시켜보세요

필러나 윤곽 시술, 눈썹 시술처럼 얼굴 인상이 달라진 뒤부터 Face ID가 나를 잘 못 알아보는 경우가 있어요. 수염을 기르거나 완전히 밀었을 때, 체중 변화가 컸을 때도 비슷한 일이 생길 수 있고요.

사실 Face ID는 화장이나 수염처럼 일상적인 외모 변화에는 알아서 적응하는 편이에요. 변화 폭이 조금 더 크더라도, 인식에 실패한 직후 암호를 입력해서 잠금을 해제하면 그 얼굴 정보가 기존 데이터에 자연스럽게 보완되면서 새 얼굴을 조금씩 학습해요.

### 1) 인식 실패 직후 암호를 입력해서 얼굴 변화를 학습시켜보세요

Face ID가 한두 번 실패했다고 바로 초기화할 필요는 없어요.

인식에 실패한 직후 아이폰 암호를 입력해서 잠금을 해제해보세요. 얼굴이 기존 정보와 어느 정도 비슷하다고 판단되면, 이때 인식된 얼굴 정보가 기존 데이터에 조금씩 추가되면서 변화한 외모를 학습해나가요.

며칠 정도 반복해서 써보면서 인식률이 다시 좋아지는지 먼저 지켜보는 걸 추천해요.

### 2) 대체 외모로 현재 모습을 추가해보세요

![](https://spacecatx.me/wp-content/uploads/2026/07/ddb569b1-87eb-4fa4-a423-4c744e733055-474x1024.png)

현재 모습과 기존 모습의 차이가 계속 크게 느껴진다면, 대체 외모를 추가하는 방법도 있어요.

```
설정 > Face ID 및 암호 > 암호 입력 > 대체 외모 설정
```

기존 Face ID 정보는 그대로 두고, 현재 얼굴을 하나 더 등록하는 방식이에요.

필러처럼 시간이 지나면서 모습이 조금씩 변하거나 화장 전후 차이가 큰 경우라면, Face ID를 아예 지우기보다 대체 외모부터 추가해보는 편이 부담이 훨씬 적어요.

### 3) 변화가 크다면 Face ID를 재설정해보세요

윤곽 수술이나 붓기처럼 기존 얼굴과 차이가 아주 크고, 대체 외모로도 인식이 잘 안 된다면 지금 얼굴 기준으로 Face ID를 다시 설정해주세요.

```
설정 > Face ID 및 암호 > Face ID 재설정 > Face ID 설정
```

Face ID 재설정은 얼굴 정보만 새로 등록하는 거라서, 사진이나 앱 데이터는 전혀 지워지지 않아요.

### 도난당한 기기 보호 때문에 재설정이 막힌다면, 평소 쓰던 장소에서 다시 시도해보세요

도난당한 기기 보호가 켜져 있으면 일부 보안 설정을 바꿀 때 Face ID 인증을 요구하는데, 이건 암호로 대신할 수 없는 경우가 많아요.

이럴 땐 먼저 집이나 직장처럼 아이폰을 평소 자주 쓰던 장소에서 다시 시도해보세요. 익숙하지 않은 장소에서는 추가 보안 요구가 걸리기 때문이에요.

다만 도난당한 기기 보호의 보안 지연 설정을 **항상**으로 해두셨다면, 익숙한 장소에서도 똑같이 적용될 수 있어요.

그래도 계속 Face ID 인증만 요구해서 설정을 바꿀 수 없다면, 무작정 초기화하기 전에 중요한 데이터부터 백업해두는 게 안전해요.

외모 변화가 원인이라면 재학습이나 새 얼굴 등록으로 해결될 가능성이 높아요. 하지만 다른 사람 얼굴도 새로 등록이 안 되거나 **Face ID를 사용할 수 없음** 같은 오류가 같이 뜬다면, 외모 변화가 아니라 TrueDepth 센서 문제일 수도 있어요.

## 3. 떨어뜨리거나 물에 닿은 뒤 Face ID가 안 된다면 하드웨어 손상을 의심해보세요

아이폰을 떨어뜨리거나 물에 빠뜨린 뒤부터 Face ID가 안 되기 시작했다면, 소프트웨어 오류보다는 TrueDepth 센서가 손상됐을 가능성이 높아요.

셀카가 잘 찍힌다고 해서 Face ID 센서까지 멀쩡한 건 아니에요. 일반 전면 카메라랑 Face ID에 쓰이는 센서는 서로 다르기 때문에, 사진은 잘 찍히는데 Face ID만 안 되는 경우도 종종 있거든요.

물에 닿았다면 일단 전원을 끄고 겉에 묻은 물기를 닦은 다음, 드라이어 같은 뜨거운 바람은 쓰지 말고 통풍이 잘되는 곳에서 충분히 말려주세요.

건조하고 재시동까지 해봤는데도 **Face ID를 사용할 수 없음** 문구가 뜨거나 얼굴이 아예 새로 등록되지 않는다면, 설정만으로는 해결이 어려워요.

최근에 액정이나 배터리, 전면 카메라를 수리한 적이 있다면 그 내용도 같이 얘기하고, 중요한 데이터를 백업한 뒤 공식 서비스센터나 공인 서비스 제공업체에서 점검받아보세요.

#### **한마디로, 낙하나 침수 이후 생긴 Face ID 문제는 센터에서 수리받는 게 제일 확실해요.**

## 4. 별다른 계기 없이 됐다 안 됐다 한다면 센서 가림부터 확인하고 증상을 기록해두세요

떨어뜨리거나 물에 빠뜨린 적도 없는데 Face ID가 간헐적으로 실패한다면, 먼저 상단 센서 주변이 가려져 있진 않은지부터 확인해보세요.

![아이폰 True depth센](https://spacecatx.me/wp-content/uploads/2026/07/ture-1024x768.png)

**TrueDepth 모듈은 아이폰 화면 앞쪽, 노치나 다이내믹 아일랜드 주변에 들어 있는 얼굴 인식 센서 묶음이에요.** 일반 셀카용 전면 카메라와는 별개로, 적외선 카메라랑 여러 센서를 이용해서 얼굴의 깊이와 형태를 입체적으로 읽고 Face ID 인증에 써요.

노치나 다이내믹 아일랜드 주변을 부드러운 천으로 닦아보고, 화면 보호필름이나 케이스가 센서 부위를 덮고 있다면 잠깐 떼어낸 상태로 다시 시도해보세요.

그다음 아이폰을 재시동하고 Face ID도 다시 등록해보세요.

그런데 새 얼굴을 등록할 때 아이폰이 얼굴을 제대로 못 잡거나, 위아래로 움직이라는 안내만 계속 반복된다면 TrueDepth 센서가 간헐적으로 고장 난 상태일 수 있어요.

실제로 센터에서는 정상 진단이 나왔는데 집에 돌아오면 다시 먹통이 되는 증상이 반복되다가, 문제 발생 장면을 직접 보여준 뒤에야 TrueDepth 모듈을 교체하고 해결된 사례도 있었어요.

이런 간헐적 오류는 막상 센터에 가면 멀쩡하게 작동해버릴 수도 있으니까, 오류 문구나 재등록 실패 장면을 다른 휴대폰으로 미리 영상 촬영해두는 걸 추천해요.

**한마디로, 센서 주변을 정리하고 재설정해도 증상이 반복된다면 영상 증거를 남긴 뒤 센터에서 점검받는 게 좋아요.**

## 5. Face ID가 회색으로 막히거나 비활성화된다면 설정 문제와 하드웨어 오류를 구분해보세요

Face ID가 단순히 인식에 실패하는 게 아니라, 설정 버튼이 회색으로 표시되거나 **Face ID가 비활성화됨**, **Face ID를 사용할 수 없음** 같은 문구가 뜨는 경우도 있어요.

이땐 **토글이 회색인 경우**, **Face ID가 비활성화된 경우**, **TrueDepth 오류가 뜨는 경우**를 나눠서 봐야 해요.

### 토글이 회색이라면 주시 관련 설정부터 확인해보세요

![](https://spacecatx.me/wp-content/uploads/2026/07/681578ae-0399-4fff-8342-ae10699cedc7-768x1024.png)

Face ID 설정 안에 있는 주시 지각 기능 토글이 회색으로 표시돼서 눌리지 않는다면, 같은 화면에 있는 Face ID 사용 시 화면 주시 필요 항목부터 확인해보세요.

```
설정 > 손쉬운 사용 > Face ID 및 주시
```

Face ID 사용 시 화면 주시 필요가 켜져 있으면, 그 아래 주시 지각 기능 토글이 회색으로 막혀서 눌리지 않을 수 있어요. 이때는 Face ID 사용 시 화면 주시 필요를 껐다가 다시 켜보거나, 필요에 따라 꺼둔 상태로 두면 주시 지각 기능 토글이 다시 활성화되는지 확인해보세요.

### Face ID가 비활성화됐다면 재시동과 업데이트부터 확인해보세요

![](https://spacecatx.me/wp-content/uploads/2026/07/b4effcc2-2a3d-4613-b792-2017b4f5910a-819x1024.png)

**Face ID가 비활성화됨** 또는 **Face ID를 사용할 수 없음** 문구가 떴다면, 먼저 아이폰을 강제 재시동하고 최신 iOS 업데이트가 있는지 확인해보세요.

재시동만으로 일시적으로 다시 작동하는 경우도 있지만, 같은 문구가 반복되거나 Face ID 재등록 자체가 안 된다면 TrueDepth 센서 문제일 가능성이 높아요.

### TrueDepth 오류 문구가 뜬다면 센터에서 점검받아보세요

**TrueDepth 카메라에 문제가 감지되었습니다** 같은 문구가 계속 나타난다면, 단순 설정 문제라기보다는 하드웨어 이상일 가능성이 커요.

**한마디로, 토글만 회색이면 주시 관련 설정부터 확인하고, Face ID 비활성화나 TrueDepth 오류가 반복된다면 센터에서 점검받는 게 좋아요.**
